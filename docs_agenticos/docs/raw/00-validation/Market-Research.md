## Para que serve
Este documento descreve a pesquisa de mercado que fundamenta as decisões de produto. Deve ser atualizado sempre que houver mudança significativa no cenário ou nas hipóteses do projeto.

## Quando atualizar
- Ao identificar novos concorrentes ou mudanças regulatórias.
- Quando novas métricas de adoção ou segmentos de cliente surgirem.
- Antes de revisar o PRD ou Roadmap.

## Como preencher
1. Preencher a secção "Descrição do Mercado" com uma análise somatória.
2. Inserir dados de fontes confiáveis (relatórios, plataformas de pesquisa).
3. Listar insights e validar com stakeholders.
4. Referenciar documentos relacionados usando links internos.

## Checklist
- [ ] Reunir dados de mercado atualizados.
- [ ] Validar hipóteses com a equipe de produto.
- [ ] Documentar fontes e data de coleta.
- [ ] Atualizar o link para o documento de Benchmark.
